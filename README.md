# 🌡️ Temperature Checker - Live Pune Weather App

A beautiful Spring Boot web application that shows real-time temperature of Pune using Open-Meteo API.

🔗 **Live Demo:** Works on `http://localhost:8080`

### ✨ Features
- Live temperature in Celsius
- Feels-like temperature, Humidity, Wind Speed
- Weather condition (Sunny, Cloudy etc.)
- Beautiful UI with Thymeleaf
- REST API integration with Open-Meteo

### 🛠️ Tech Stack
- Java 17
- Spring Boot 3
- Thymeleaf
- Maven
- Open-Meteo Weather API
- HTML / CSS

```bash
git clone https://github.com/dalvi24sakshi/temperature-checker.git
